Reject unsafe static_template.file references in plugin manifest gene…
cb27909 
…ration (GHSA-4jwf-m4wg-8p66)

Both x-ai-adaptive-card and x-ai-capabilities extensions can populate
response_semantics.static_template.file in the generated plugin manifest.
An attacker-controlled OpenAPI description could set this to an absolute
path, URI, or '..' traversal, causing the generated manifest to reference
files outside the plugin package (CWE-22/CWE-829).

Validate the file reference at emission time in both code paths: reject
absolute URIs, POSIX/UNC rooted paths, Windows drive paths, and parent
-directory segments. Unsafe references are skipped with a warning; the
adaptive-card path falls back to Kiota's own safe placeholder template.
Inlined Adaptive Cards (no file key) and JSONPath fields are untouched.
