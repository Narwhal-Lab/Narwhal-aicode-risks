MindsDB Path Traversal to RCE (CVE-2026-27483)

THW AI Reporter
February 24, 2026
2 min read

Summary

CVE-2026-27483 identifies a high-severity path traversal vulnerability in MindsDB, an AI platform for enterprise data. Rated 8.8 on the CVSS scale, this flaw allows an authenticated attacker to write arbitrary files to arbitrary locations on the server. The vulnerability, published on February 24, 2026, ultimately leads to remote command execution (RCE).

The Bug

The core issue lies within MindsDB’s /api/files interface, specifically within its “Upload File” module. This endpoint handles multipart file uploads. The vulnerability stems from a lack of proper security checks on the uploaded file path. Attackers can leverage ../ sequences in the filename field of their upload request to perform path traversal.

Crucially, the file write operation occurs *before* any filename filtering functions, such as clear_filename and save_file, are invoked. This means the system writes arbitrary content with an attacker-controlled filename and path without validation. The ability to write arbitrary content to any server path is a critical primitive for achieving remote command execution.

Attack Requirements

Exploitation of CVE-2026-27483 requires an authenticated attacker. The vulnerability exists in MindsDB versions prior to 25.9.1.1. No specific network position beyond access to the MindsDB instance is detailed, but authenticated access implies the attacker can reach the application’s API endpoints.

Exploitation

An attacker needs to first authenticate to the MindsDB platform. Once authenticated, they can craft a multipart file upload request targeting the /api/files endpoint. Within this request, the filename field can be manipulated using path traversal sequences (e.g., ../../../path/to/target/file.ext) to specify an arbitrary write location on the server’s filesystem.

The content of the uploaded file can be entirely controlled by the attacker. Since the file write operation happens before any filename or file type filtering, an attacker can upload malicious content, such as a web shell or a configuration file designed to trigger code execution, to a sensitive location. This direct file write capability to arbitrary paths is what enables remote command execution.

References

  • CVE-2026-27483

Fix

MindsDB version 25.9.1.1 contains the patch for this vulnerability. Users should upgrade to this version or newer to mitigate the risk.
