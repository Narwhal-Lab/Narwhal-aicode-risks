Require explicit conversation ID in chat memory advisors
- Remove ChatMemory.DEFAULT_CONVERSATION_ID and the .conversationId() builder method from MessageChatMemoryAdvisor, PromptChatMemoryAdvisor, and VectorStoreChatMemoryAdvisor. The conversation ID must now be supplied explicitly via the advisor context on every call; omitting it throws IllegalArgumentException. - Update BaseChatMemoryAdvisor.getConversationId() to the single-argument form and add upgrade notes and documentation for the breaking changes. - Fix test and doc gaps after removing default conversation ID - Supply ChatMemory.CONVERSATION_ID at all call sites that were missing it: OpenAiChatClientMemoryAdvisorReproIT, AbstractToolCallAdvisorIT, and ChromaVectorStoreAutoConfigurationIT (including ChatClientRequest and ChatClientResponse context). - Update chatclient.adoc to show the required CONVERSATION_ID param in the advisor ordering example and add an IMPORTANT note in the Chat Memory section. Signed-off-by: Christian Tzolov <christian.tzolov@broadcom.com>
