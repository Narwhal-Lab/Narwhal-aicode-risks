How to fix?

Upgrade github.com/Tencent/WeKnora/internal/utils to version 0.2.12 or higher.

Overview

Affected versions of this package are vulnerable to SQL Injection inadequate recursive validation of PostgreSQL array and row expressions in the validateNode function. An attacker can execute arbitrary SQL functions and achieve code execution on the database server by crafting malicious queries that embed dangerous function calls within array or row expressions, bypassing existing validation checks.
