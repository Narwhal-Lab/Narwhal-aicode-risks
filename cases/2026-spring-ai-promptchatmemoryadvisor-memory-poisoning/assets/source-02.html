Spring AI: Prompt Injection via Memory Poisoning in PromptChatMemoryAdvisor

High severity GitHub Reviewed Published May 12, 2026 to the GitHub Advisory Database • Updated May 18, 2026
Vulnerability details Dependabot alerts 0

Package

org.springframework.ai:spring-ai-client-chat (Maven)

Affected versions

< 1.0.7
>= 1.1.0-M1, < 1.1.6

Patched versions

1.0.7
1.1.6

Description

A malicious user could craft input that is stored in conversation memory and later interpreted by the model in an unintended way. Applications using the affected advisor with user-controlled input may be susceptible to manipulation of model behavior across conversation turns.
