Evidence Summary

The GitHub issue reports a supply-chain compromise in mistralai==2.4.6. It describes an unexpected change in src/mistralai/client/__init__.py that runs a background task on Linux during import.

The report states that the added code checks an environment variable, downloads a second-stage payload from a suspicious IP address, stores it under a temporary filename, and starts it as a detached process. The IP address, payload filename, and command details are intentionally redacted in this local archive.

The issue is used in the case write-up as code-level ecosystem evidence supporting the import-time dropper behavior described by the GitHub Advisory and Mistral security advisory.
