Hugging Face text-generation-inference Denial of Service (CVE-2026-0599)

  • Vulnerability
  • Protection
Check Point Reference: CPAI-2026-5496
Date Published: 31 May 2026
Severity: High
Last Updated: Sunday 31 May, 2026
Source:
Industry Reference:CVE-2026-0599
Protection Provided by:

Security Gateway
R81, R80, R77, R75
Who is Vulnerable? Hugging Face text-generation-inference 3.3.6
Vulnerability Description A denial of service vulnerability in Hugging Face text-generation-inference allows unauthenticated remote attackers to exploit unbounded external image fetching during input validation in VLM mode. This can lead to resource exhaustion, including network bandwidth saturation, memory inflation, and CPU overutilization, potentially crashing the host machine.

Protection Overview

This protection detects attempts to exploit this vulnerability.

In order for the protection to be activated, update your Security Gateway product to the latest IPS update. For information on how to update IPS, go to SBP-2006-05, click on Protection tab and select the version of your choice.

Security Gateway R81 / R80 / R77 / R75

  1. In the IPS tab, click Protections and find the Hugging Face text-generation-inference Denial of Service (CVE-2026-0599) protection using the Search tool and Edit the protection's settings.
  2. Install policy on all Security Gateways.

This protection's log will contain the following information:

Attack Name:  Application Intelligence.
Attack Information:  Hugging Face text-generation-inference Denial of Service (CVE-2026-0599)
